# Security policy

Report suspected vulnerabilities through GitHub private vulnerability reporting:
open this repository's **Security** tab, select **Advisories**, then
**Report a vulnerability**.

Include the affected version, reproduction steps, and expected impact. Remove
credentials and personal data from examples. Do not report vulnerabilities in
public issues or upload private clips or drawings.

Private reporting becomes available when the repository maintainer enables it on
GitHub. This local repository does not yet have a hosted reporting channel.
