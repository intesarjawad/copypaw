# ADR-003: Vendor the ONNX subset of rtmlib

Status: Accepted; ONNX subset vendored.
Date: 2026-11-05.

## Context

rtmlib 0.0.16 supplies the required animal models, but depends on both
opencv-python and opencv-contrib-python. Those distributions and the chosen
opencv-python-headless distribution all write the cv2 package. Its Animal
solution also needs an explicit class filter to prevent people winning the
largest-box selection.

## Decision

I vendor the Apache-2.0 subset into copypaw/vendor/rtmlib_onnx: tools/base.py
with only the ONNX Runtime path, object_detection/yolox.py and multiclass_nms,
pose_estimation/vitpose.py, bbox_xyxy2cs, top_down_affine and post_dark_udp.
Remove the opencv-dnn and OpenVINO branches. Preserve licence headers, record
version 0.0.16 and each modification in NOTICE, and add adjacent typed stubs for
the names first imported by package code, as in ADR-002.

## Consequences

Only the headless OpenCV distribution enters the environment. The project owns
updates to the vendored subset. I explicitly filter COCO animal classes and
track the intended animal. Detector input colour order needs regression
coverage and independent model provenance, as recorded in [ADR-001](ADR-001.md).
