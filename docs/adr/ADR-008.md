# ADR-008: Defer MoCapAnything V2

Status: Accepted; GPU fit and output compatibility unmeasured.
Date: 2026-11-05. Upstream sources checked: 2026-11-06 UTC.

## Context

I target a laptop CPU and a two-dimensional drawing. A learned three-dimensional
pipeline adds model downloads, GPU uncertainty and a different rigging path.
My available GPUs each have 6 GB; I have not measured this pipeline on them.

## Decision

I keep MoCapAnything V2 outside the CPU release and `uv.lock`. Before adopting
it, I need a pinned environment, measured peak VRAM, seconds per clip and BVH
joint compatibility. I would also need to replace the RMBG dependency with a
permissively licensed matte model. BiRefNet is an option with published MIT
licensing; replacement quality and integration remain untested.

## Consequences

The CPU release does not depend on an unmeasured GPU fit or a different rigging
path. CPU users do not need torch or CUDA downloads. I will recheck dependency
licences before adoption.

## Not independently confirmed

I have not measured peak VRAM, GPU runtime, CPU viability, full-pipeline precision
or compatibility with Copypaw's joint mapping. The inspected instructions do not
supply a minimum VRAM guarantee. I have not established a tested Python minimum.
The RMBG card's linked full licence agreement returned HTTP 404, and no LICENSE
file was available at its pinned model revision; I confirmed only the card's
stated restrictions and the source's exception notice. A complete legal text
comparison and a BiRefNet replacement evaluation remain undone. I downloaded no
MoCapAnything, RMBG or BiRefNet weights.
